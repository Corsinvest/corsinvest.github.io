cv4pve suite

For Proxmox VE

Web administration, tools and API libraries. They run outside the nodes, with nothing to install on them.

Web interface

  • cv4pve-admin Professional administration interface for Proxmox VE with advanced features and support. CE EE

Tools

  • cv4pve-report Inventory of a whole Proxmox VE cluster in Excel, HTML or JSON: the RVTools for Proxmox VE.
  • cv4pve-diag Health checks and diagnostics for Proxmox VE.
  • cv4pve-autosnap Automatic snapshots of Proxmox VE virtual machines and containers, with retention.
  • cv4pve-node-protect Configuration backup for Proxmox VE nodes over SSH: network, storage, cluster and certificates in one archive per node.
  • cv4pve-metrics-exporter Prometheus exporter for Proxmox VE: nodes, VMs, containers, storage, HA, replication, backup coverage, subscription and SMART, from outside the cluster.
  • cv4pve-cli The whole Proxmox VE API from the command line, like kubectl for Kubernetes: saved contexts for several clusters, 327 built-in aliases and tab completion that reads the live cluster.
  • cv4pve-pepper Open the SPICE or VNC console of a Proxmox VE VM or container with one command, from your desktop, a script or a shortcut.
  • cv4pve-vdi Desktop VDI client for Proxmox VE: SPICE, VNC, RDP and SSH to your VMs and containers, without the web UI.
  • cv4pve-botgram Telegram bot to manage and monitor a Proxmox VE cluster from a phone.

API libraries

  • cv4pve-api-dotnet Proxmox VE API client for .NET: the whole API as typed C# calls, with helpers for VMs, containers, tasks and command line tools.
  • cv4pve-api-java Proxmox VE API client for Java: the whole API as Java calls that follow the tree of the API, with results as JSON, tasks and API token or password login.
  • cv4pve-api-javascript Proxmox VE API client for JavaScript and Node.js: the whole API as calls that follow the tree of the API, with results as JSON, tasks and API token or password login.
  • cv4pve-api-php Proxmox VE API client for PHP: the whole API as PHP calls that follow the tree of the API, with results as objects or arrays, tasks and API token or password login.
  • cv4pve-api-powershell PowerShell module for the Proxmox VE API: automate clusters, nodes, VMs and containers from PowerShell, the PowerCLI for Proxmox VE.
